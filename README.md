# Reto: Componentes Padre e Hijo

Proyecto desarrollado en Angular para demostrar
la comunicación entre componentes mediante
@Input, @Output y EventEmitter.

## Funcionalidades

- Visualización de tres cursos.
- Inscripción a cursos.
- Cálculo del total a pagar.
- Prevención de inscripciones duplicadas.

## Ejecución

npm install
npm start
